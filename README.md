# Chaos Condensate Homebrew Tap

This tap distributes command-line tools from
[Chaos Condensate](https://chaoscondensate.com/).

## Forecast Ledger CLI

After the first public release, install `forecast-ledger` with:

```sh
brew install --cask chaoscondensate/tap/forecast-ledger
```

Upgrade or uninstall it with:

```sh
brew upgrade --cask forecast-ledger
brew uninstall --cask forecast-ledger
```

The source code, documentation, checksums, and release notes are available in
the [`chaoscondensate/cli`](https://github.com/chaoscondensate/cli) repository.

Files under `Casks/` are generated and updated by the project's reviewed
GoReleaser workflow. Do not edit a generated cask by hand.
